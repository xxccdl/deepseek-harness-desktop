    安装

    在 DeepSeek Harness 里打开本页，点安装即可：包会下载到本地 plugins/@deepseek-ai/<id>，写入 profile 的 patch 层，热重载后立即可用。若校验不通过，安装会整体回滚，不会影响正在运行的应用。

    发布

    把 DSH 切到创造模式让 AI 写好插件，对话结束后点底部的插件发布按钮，AI 会打包并推送到这里。也可以直接调用接口：

    curl -X POST http://<market>/api/plugins \
  -H "X-Market-Meta: $(echo -n '{"title":"我的插件","category":"开发工具"}' | base64 -w0)" \
  --data-binary @my-plugin.tgz

    包要求

    根目录含 package.json（含 name、version、入口文件），脚本为纯 JS、无 npm 依赖，所有 .js 通过 node --check。首次发布返回的发布令牌请在后续更新时带上。
