# 悬浮球（Floating Ball）

界面右下角一颗可拖拽的**快捷操作球**。点一下展开快捷操作面板，拖一下随手挪位置，松手自动吸附到最近的左/右边缘。

## 功能

点开球之后的 5 个快捷操作：

| 操作 | 说明 |
| --- | --- |
| **新建会话** | 直接开一个新会话（沿用当前/最近的工作区） |
| **回到底部** | 对话区平滑滚到最新消息 |
| **回到顶部** | 对话区平滑滚到最早消息 |
| **切到深色 / 切到浅色** | 按当前主题显示相反项，一点切换 |
| **藏起来** | 收起悬浮球，窗口右边缘留一条细把手，点一下唤回 |

## 交互

- **拖拽**：按住球体任意拖动，松手后吸附到最近的左边缘或右边缘；位置会被记住（localStorage），刷新和重启后仍在原处。
- **点开/收起**：单击球体展开或收起；点击面板以外的任意位置也会收起。
- **面板方向**：球在下方时菜单向上展开，拖到上方时自动改为向下展开，永远不会跑出屏幕。
- **球在左半屏**时菜单左对齐，在右半屏时右对齐，跟着球走。
- **键盘**：球可获得焦点，`Enter` / `Space` 展开收起。
- 隐藏状态同样被记住。

## 实现说明

- 纯客户端插件，只占一个槽位：`shell.overlay`（entry id `floating-ball`，order 70）。
- 位置、隐藏状态、展开状态全部本地持有；`Esc`/遮罩点击即收起，不停留任何全局副作用。
- 主题相关配色走主题变量（`--dsw-alias-brand-primary`、`--dsw-alias-bg-overlay`、`--dsw-alias-border-l2`、`--dsw-alias-label-primary`），深浅色主题下都成立；球体本身使用品牌蓝渐变，保证白点图标在两种主题下都清晰。
- 「回到顶部/底部」不依赖任何写死的产品选择器：它按「最大可滚动区域」通用识别对话列，识别不到就安全地什么都不做。
- 尊重 `prefers-reduced-motion`：系统开启减弱动画时，浮动、脉冲、入场动画全部关闭。
- 宿主半边（`lib/index.js`）不注册任何服务或工具，功能全在浏览器侧。

## 安装

在 DSH Web GUI 的插件市场里安装并启用即可，无需额外配置。
