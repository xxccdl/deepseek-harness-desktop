# 小恐龙跳跃 / Dino Jump

界面右下角一个直接开玩的横版跳跃小游戏。零 npm 依赖，零资源文件。

## 玩法

| 操作 | 效果 |
| --- | --- |
| `空格` / `↑` / 点击画面 | 恐龙起跳（落地后可再跳） |
| 鼠标移出画面 | 自动暂停 |
| `🔊` / `🔇` | 开关音效 |
| `—` | 收起面板，右下角留一个 🦖 按钮 |
| `重新开始` | 撞到仙人掌后重开一局 |

- 地面滚出**矮胖**（10×20）与**高瘦**（14×30）两种仙人掌。
- 横向速度从 `4.4` 随存活时间线性升到 `9.5`，越跑越快。
- 得分按存活时间累计（每 4 tick 记 1 分），最高分写进 `localStorage`，键为 `dsh.dino-game.best`。

## 实现

- 只占 `shell.overlay` 一个槽位，id `dino-game`，order `80`。该层点击穿透，不遮挡应用。
- 游戏循环是 `window.setInterval`（16ms），指针离开或游戏结束时暂停。
- 键盘监听挂在 `canvas.ownerDocument` 上，且只在指针悬停或 canvas 聚焦时生效，不会抢走输入框的空格键。
- 音效用 `WebAudio` 现场合成（起跳方波、撞击锯齿波），因此包内没有任何图片或音频资源。
- 配色全部走 `--dsw-alias-*` 主题变量，深浅色跟随界面。
- 收起面板时 `Game` 组件整体卸载（靠 `key` 重挂载），循环和监听随组件一起清掉。

## 结构

```
package.json     入口与 dsh.client 声明
market.json      市场展示信息
lib/index.js     host 半边（空实现，仅作为包入口）
lib/client.js    全部逻辑：module-loader 包装 + 组件 + 游戏循环
```
