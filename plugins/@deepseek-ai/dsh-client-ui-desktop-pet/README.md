# DeepSeek 桌宠

在界面**右下角的浮动层**养一只蓝色小鲸鱼：它会自己漂浮、摆尾、眨眼，被你戳会回应你，还会按心情换表情。

## 特性

- **会动的鲸鱼**：整条鲸鱼用内联 SVG 画出来，身体持续上下浮动并轻微摇摆，尾鳍摆动、胸鳍扇动、眼睛定时眨动、头顶冒水汽 —— 全部是 CSS 动画，不占用主线程。
- **拖动换位置**：按住鲸鱼就能拖到任意位置，松手后位置会记住（同一次会话内换页面也还在），并且永远被夹在视口内，不会拖到看不见的地方。
- **点它有反应**：点一下鲸鱼，它会冒一句话回应你；双击会主动跟你说一句随机的话。
- **5 种表情**：开心 / 发呆 / 思考 / 警觉 / 睡觉。表情不只是换个标签，而是直接改变画面：
  - `开心` 身边冒金色小星星
  - `思考` 尾巴摆得更慢，旁边浮一个琥珀色小点
  - `警觉` 整体泛起品牌蓝光晕，尾巴甩得更快
  - `睡觉` 闭上眼睛、褪色、头顶飘出 `z`
- **小控制面板**：点鲸鱼右上角的 ⚙ 打开 —— 选表情、用方向键挪位置、「说一句」、「回角落」、「先藏起来」。
- **可收可放**：藏起来后右下角留一个 🐳 小按钮，随时把它叫回来。
- **跟随主题**：气泡、面板、按钮的颜色全部走 `--dsw-alias-*` 主题变量，浅色深色自动适配。

## 使用

安装后鲸鱼会出现在界面右下角。

- **换位置**：直接拖动鲸鱼，或用面板里的 ← → ↑ ↓。
- **让它说话**：点一下鲸鱼，或双击，或面板里的「说一句」。
- **换表情**：点 ⚙ 打开面板选，或直接告诉我（见下）。
- **藏起来**：面板里的「先藏起来」；点右下角的 🐳 恢复。
- **回角落**：面板里的「回角落」。

## 说明

- 纯前端实现，宿主侧不做任何事；`lib/index.js` 只是加载器要求的入口。
- **零 npm 依赖**：只用 `react` 与宿主已有的 `slots` 服务。
- 只占用 `shell.overlay` 一个槽位。这一层本身是**点击穿透**的，只有鲸鱼、气泡和面板自己接管指针事件，因此不会挡住下面的应用。
- 位置与表情保存在内存里，刷新页面会回到默认状态。
