# 世界时钟

在**侧栏底部的状态区**放一个常驻时钟，点开后是一个世界时钟面板。

## 特性

- **秒级本机时钟**：展开侧栏时显示 `时:分:秒` + 星期/日期/时区名；收起成窄栏时只显示 `时:分`。
- **世界时钟面板**：多城市实时对照，默认带本机、东京、伦敦、纽约，可自行增删（可选上海、首尔、新加坡、迪拜、柏林、洛杉矶、悉尼等 19 个时区）。
- **真实时区计算**：每行显示 IANA 时区名与 UTC 偏移，全部由浏览器 `Intl` 计算，不写死偏移量，因此夏令时切换会自动跟上。
- **跨日标注**：当某城市已经不是本机日历日时，自动标出「昨天 / 明天」或相差天数。
- **倒计时**：开始 5 分钟、暂停、继续、清零，另有 15 / 25 分钟快捷档。
- **跟随主题**：颜色全部走 `--dsw-alias-*` 主题变量，浅色深色自动适配。

## 使用

安装后在侧栏底部即可看到时钟，点击展开面板。

- 加城市：在面板底部下拉里选一个时区，点「＋ 加城市」。
- 去城市：悬停某一行，点右侧的 `×`；「本机」一行固定保留。
- 倒计时：点「开始 5 分钟」，运行中可暂停、继续或清零。

面板位置固定在左下角，覆盖在应用之上但不遮挡点击（只有面板本身接收指针事件）。

## 说明

- 纯前端实现，宿主侧不做任何事；`lib/index.js` 只是加载器要求的入口。
- **零 npm 依赖**：只用 `react` 与宿主已有的 `slots`、`locale` 服务。
- 时区换算依赖浏览器的 IANA 时区数据库。
